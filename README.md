# 📝 Task Manager - Home Setup Planner

Welcome to the **Task Manager** project! This simple yet efficient app helps you plan, organize, and complete your home-related tasks in categorized lists. Each task list can track incomplete items and update in real time — all stored locally in your browser.

## 🚀 Features

- 📁 **Multiple Lists** – Organize tasks into different categories (e.g., Home Setup, Shopping, To-Do).
- ➕ **Add New Lists & Tasks** – Easily create new lists and add tasks to them.
- ✅ **Mark Tasks as Complete** – Track progress with a visual indication of completion.
- ❌ **Delete Tasks or Lists** – Remove any task or an entire list as needed.
- 💾 **Persistent Storage** – All data is saved using `localStorage`, so your lists remain even after refreshing the page.
- 🎉 **Task Completion Feedback** – See a friendly message once all tasks are done.

## 🛠️ Built With

- **React** (with Hooks like `useState`, `useEffect`)
- **Vite** – For fast development and build tooling
- **JavaScript** – For logic and DOM manipulation
- **CSS** – Custom styles
- **localStorage** – For client-side data persistence
